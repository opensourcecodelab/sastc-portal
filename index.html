⚠️ আপনার নিজস্ব API Key যুক্ত করার পরামর্শ

সিস্টেমে থাকা ডিফল্ট/ফ্রি API Key-টি সব ব্যবহারকারীর জন্য উন্মুক্ত থাকায় যেকোনো মুহূর্তে এর রিকোয়েস্ট লিমিট (Rate Limit) শেষ হয়ে সার্ভিস বাধাগ্রস্ত হতে পারে।

কেন নিজস্ব কি ব্যবহার করবেন?
  • কোনো লিমিটেশনের ঝামেলা ছাড়া দ্রুত রেসপন্স পাওয়া যাবে।
  • আপনার এনালাইসিস বা ডেটা প্রসেসিংয়ের ধারাবাহিকতা বজায় থাকবে।
  • রিকোয়েস্ট লিমিটের ঝামেলা এড়াতে আপনি চাইলে একাধিক বা আনলিমিটেড API Key যুক্ত করে রাখতে পারবেন।

💬 API Key সেটআপ করতে সমস্যা হলে কিংবা যেকোনো ফিডব্যাক জানাতে আমাদের টেলিগ্রামে মেসেজ দিন।
